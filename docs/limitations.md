# Ограничения

- Платежей в данных нет. Главный риск ворот (выручка) не проверен.
- SRM пограничный: p = 0,0086. Порог 0,001 я выбрал, уже зная этот p-value, при 0,05 проверка бы сработала. Причину по данным не установить.
- Дизайн теста записан после того, как я увидел доли по группам. Правило решения выведено из логики теста, но полноценной пререгистрацией это не назвать.
- Нет даты установки и уровня игрока: эффект новизны не проверить, игроков, не дошедших до 30 уровня, не отфильтровать (они видят одинаковую игру в обеих группах и размывают разницу).
- По ретеншну данные только за 1-й и 7-й день, долгий ретеншн не виден.
- В gate_30 есть игрок с 49 854 раундами, скорее всего бот или сбой логирования. Из основного анализа я его не исключал: вывод по раундам от него зависит, вывод по ретеншну нет.
- CUPED показан только на синтетике: метрики до теста в данных нет, а sum_gamerounds измерена после воздействия.
- Симуляции мощности предполагают честную рандомизацию и пограничный SRM не учитывают.
